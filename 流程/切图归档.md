# 切图归档

> 触发：收到设计师发来的切图包、弹窗包、页面更新图（微信、邮件、网盘均适用）。
> 输出：素材归位到 `~/Documents/卓望工作/各个分省/<省份>/<类型>/_当前/`，旧版进 `_历史/`。
> 规范依据：`卓望.md` →「素材归档规范」。本文件只写动作，不复述规范。

## 步骤

### 1. 解压后先看日期，不要看序号

系统会给重名包自动加序号（`切图 2`、`切图 3`）或下载后缀（`(1)`、`(3)`）。**这些数字只反映解压／下载顺序，不代表版本新旧。**

判断依据只有两个：文件修改日期，或文件名里自带的日期（如 `8.25贵州切图`）。

### 2. 确认省份与类型

- 省份：看文件名，或打开任意一张图看主视觉
- 类型：切图 / 弹窗 / 原型 / 文档
- 判断不出来 → 放 `各个分省/_待归类/`，**不要猜着放**，猜错比不放更难找

### 3. 旧版整包退休

```
mv "<省份>/<类型>/_当前/<旧包名>" "<省份>/<类型>/_历史/<收到日期>_<旧包名>"
```

日期格式 `YYYYMMDD`，取旧包的修改日期而非今天。

### 4. 新包进 `_当前/`

保留设计师的原包名和内部结构，不要拆散重组——下次对方说「改了 3-抽奖机 里那张」时，路径能对得上。

### 5. 检查 `_当前/` 是否只剩一份

同一类型下允许有多个包**并存**的唯一情况：它们是不同用途（如「页面切图」和「赛事切图」），不是同一批的不同版本。

同一批的不同版本同时出现在 `_当前/` 里 → 说明第 3 步漏做了。

## 验收清单

- [ ] `_当前/` 里没有同一批素材的两个版本
- [ ] `_历史/` 子目录名都带 `YYYYMMDD_` 前缀
- [ ] 下载文件夹里对应的原包已清理（确认新位置可用之后）
- [ ] 没有新建「切图 2」「切图 3」这类平行目录
- [ ] 判断不出归属的已进 `_待归类/`，没有猜着乱放

## 坑

- **不要按活动分目录。** 活动是月度滚动的，按活动分会无限增长，且同省素材被切散。活动名写进文件名即可。
- **不要为了去重打乱结构。** 2026-09-21 盘点：2175 个文件里全部重复仅 23 MB。整理是为了好找，不是为了省空间。
- **素材库不进 git。** 它在 `~/Documents/卓望工作/` 下，与本仓库无关；本仓库只存规范，不存素材本体。
