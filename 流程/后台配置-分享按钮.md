# 后台配置-分享按钮

> 输入：已建好的省级福利中心活动页面、要跳转的分享页 group 节点。
> 输出：页面上可点击、能拉起分享面板的分享按钮。
> 前置：先跑 [开工检查.md](开工检查.md)。
> 适用：咪咕视讯「H5 分省营销活动」后台，各省通用。

## 步骤

### 1. 在页面区段列表找到分享按钮组件

进入该省活动页面的后台配置，在右侧组件列表中定位 **分享按钮**（类型为「按钮」，非「图片」）。

确认 **状态为「上线」**——下线状态的组件前台不展示，配置了也看不到效果。

![步骤1 在区段列表找到分享按钮](附件/分享按钮-1-找组件.png)

### 2. 进入组件编辑，走到「展现数据」点「事件」

点击组件名进入编辑，配置分四步：基本信息 → 展现样式 → **展现数据** → 节目数据。

在第 3 步「展现数据」中：

- 编辑模式：**普通模式**
- 样式模式：**基本样式**
- 在「事件编辑」一行点 **事件** 按钮，展开事件配置区

![步骤2 在展现数据里点事件](附件/分享按钮-2-进事件.png)

### 3. 填写事件配置

| 字段 | 填法 |
|---|---|
| 事件类型 | 选 **跳转到分享页**（JUMP_SHARE） |
| 分享主标题 | 活动主题词，与页面头图口径一致 |
| 分享副标题 | 一句话利益点 |
| 分享图片 | 上传分享卡片缩略图 |
| **分享地址** | **必须 https**，见下方红线 |
| group 节点 | 填分享引导页区段的节点 ID（从区段列表该项名称后缀复制） |
| 额外需要参数 | 无特殊需求留空 |

![步骤3 事件配置字段](附件/分享按钮-3-填配置.png)

### 4. 保存并验证

保存后用「环境预览」自测：点击分享按钮 → 能正常拉起分享面板 → 分享出去的卡片标题、图片、落地页均正确。

## 红线与坑

- **分享地址必须用 https。** 后台会给出橙色警告：「http 链接可能存在被恶意劫持风险，客户端会对 http 链接进行拦截访问」。填了 http 的结果是用户点分享后打不开落地页，且不一定在预览环境暴露。配置完务必回读这一栏。
- **group 节点不要手敲。** 从左侧区段列表里「分享引导页-<一串 ID>」的名称后缀直接复制，手敲错一位就会跳到空白页。
- **组件类型别选错。** 分享按钮是「按钮」类型；同页面里「活动规则」「背景图」等是「图片」类型，不带事件配置能力。
- **改完先看状态。** 列表里有「上线／下线」标记，配置正确但状态是下线，前台依然不展示。

## 验收清单

- [ ] 分享按钮组件状态为「上线」
- [ ] 事件类型为「跳转到分享页」
- [ ] 分享地址为 https，且真机点开能落到活动页
- [ ] group 节点与分享引导页区段 ID 一致
- [ ] 分享主副标题、分享图与页面主视觉口径一致
- [ ] 环境预览中完整走通一次分享链路
